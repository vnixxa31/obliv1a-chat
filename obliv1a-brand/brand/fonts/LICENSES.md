# Typeface licences

All three families are licensed under the **SIL Open Font License 1.1**, which
permits redistribution, embedding and commercial use. The full licence text for
each accompanies the font files in this directory, as the OFL requires.

| Family | Files | Foundry | Upstream | Licence |
|---|---|---|---|---|
| Archivo | `archivo-var.woff2` | Omnibus-Type | https://github.com/Omnibus-Type/Archivo | `OFL-Archivo.txt` |
| Bodoni Moda | `bodoni-moda-var.woff2`, `bodoni-moda-italic-var.woff2` | Indestructible Type | https://github.com/indestructible-type/Bodoni | `OFL-BodoniModa.txt` |
| JetBrains Mono | `jetbrains-mono-var.woff2` | JetBrains | https://github.com/JetBrains/JetBrainsMono | `OFL-JetBrainsMono.txt` |

Each `.woff2` is a **latin subset** of the upstream variable font, converted for
web delivery. Subsetting and format conversion are permitted modifications under
the OFL; none of the files is renamed to a Reserved Font Name.

## The marks

The Obliv1a marks in `../marks/` are original work, derived from Archivo outlines
instanced at `wdth 62 / wght 800` and then modified. The OFL explicitly permits
using font outlines in derivative artwork, and the resulting artwork is not
itself bound by the OFL. `_build.py` records exactly how they are produced.
